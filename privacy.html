Privacy policy

ClipMaxx · last updated 15 November 2026

ClipMaxx is a personal tool that runs only on its owner's own computer. It makes short video clips and, after the owner approves them, uploads them to the owner's own YouTube channels. This policy explains what Google account data it uses and how.

What ClipMaxx accesses

When the owner signs a channel in, ClipMaxx asks Google for two permissions on that YouTube account:

  • Upload videos (youtube.upload): to upload the clips the owner has approved, with their title, description and tags.
  • View the YouTube account (youtube.readonly): to read the channel's name and ID, so the right channel is used, and to check an uploaded video's privacy status.

ClipMaxx does not read, change or delete any other videos, comments, subscribers, analytics or personal information.

How the data is stored

The sign-in tokens Google returns are stored only on the owner's computer, in ClipMaxx's own data folder. They are not sent to any server other than Google's, are not shared with anyone and are not sold. ClipMaxx has no servers, no user accounts, no advertising and no analytics.

Who uses it

ClipMaxx is used only by its owner, on the owner's own channels. It does not collect data about anyone else.

Google API Services

ClipMaxx's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting ClipMaxx's data folder removes the stored tokens from the computer.

Changes and contact

Changes to this policy are published on this page. Questions can be raised through the issues page of the GitHub repository that hosts this site.
